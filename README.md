# Deepika AI Feedback Tool

## Project Overview

An AI-powered feedback tool that helps users receive intelligent feedback and suggestions.

## Features

* AI-generated feedback
* Frontend UI using React
* Backend API using Node.js
* Clean user interface
* Real-time interaction

## Tech Stack

### Frontend

* React
* Vite
* JavaScript

### Backend

* Node.js
* Express.js

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```
